Voor de beheerder

Vestigingen & clusters

Drie kolommen: vestigingen → clusters → kluisjes. Toevoegen, hernoemen, soft-deleten. Magister-locaties hier koppelen.

Gebruikers & rollen

Beheerder of medewerker. Medewerkers gekoppeld aan specifieke vestiging(en).

Eigen branding

Schoolnaam, logo, hoofdkleur. Per school anders, zelfde codebase.

Import-flow

XLSX uploaden → preview → prefixen mappen naar vestigingen → importeren. 2.500 kluisjes in 30 seconden.

De bouwstenen

Software

  • Backend: Python / Flask
  • Frontend: React + Tailwind
  • Database: SQLite
  • Hosting: Proxmox LXC (Debian 12)

Integraties

  • Login: Microsoft Entra (SSO)
  • Leerlingen: Magister Medius (nachtelijke sync)
  • Backups: 3 lagen — in-app, host-cron, weekly snapshot
  • PDF: server-side gegenereerd
